4. WORKTREE FLOW (Pattern Commit — Step 6.5.7)
===============================================

Reviewer is actively working on their branch (e.g., Outage-2272)
with staged, unstaged, and untracked changes.
This flow runs in the BACKGROUND — zero interference.


   ╔═════════════════════════════════════════════════════╗
   ║ 0. PRE-CHECK: MR already merged?                   ║
   ║                                                     ║
   ║    Yes → SKIP entire worktree flow                  ║
   ║          (branch may be deleted, commit would       ║
   ║           never reach target branch)                ║
   ╚══════════════════════╤══════════════════════════════╝
                          │ Not merged — proceed
                          ▼
   ┌─────────────────────────────────────────────────────┐
   │ 1. Create temp worktree                             │
   │    git worktree add /tmp/shipit-peer-review-...     │
   │    on MR source branch (e.g., outage-2312)          │
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ┌─────────────────────────────────────────────────────┐
   │ 2. Pull latest                                      │
   │    cd /tmp/shipit-... && git pull origin outage-2312 │
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ┌─────────────────────────────────────────────────────┐
   │ 3. Write SKILL.md in worktree directory             │
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ╔═════════════════════════════════════════════════════╗
   ║ 4. SAFETY CHECK #1                                 ║
   ║    git status --porcelain                          ║
   ║    Only SKILL.md changed?                          ║
   ║                                                    ║
   ║    Other files? → ABORT, clean up worktree         ║
   ╚════════════════════════╤════════════════════════════╝
                            │ Only SKILL.md
                            ▼
   ┌─────────────────────────────────────────────────────┐
   │ 5. git add .claude/skills/pr-review-patterns/SKILL.md│
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ╔═════════════════════════════════════════════════════╗
   ║ 6. SAFETY CHECK #2                                 ║
   ║    git diff --cached --name-only                   ║
   ║    Only SKILL.md staged?                           ║
   ║                                                    ║
   ║    Other files? → git reset HEAD, ABORT, clean up  ║
   ╚════════════════════════╤════════════════════════════╝
                            │ Only SKILL.md
                            ▼
   ┌─────────────────────────────────────────────────────┐
   │ 7. git commit -m "chore: update pr-review patterns  │
   │    from peer review of <TICKET_KEY>"                │
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ┌─────────────────────────────────────────────────────┐
   │ 8. git push origin outage-2312                      │
   └──────────────────────┬──────────────────────────────┘
                          │
                          ▼
   ┌─────────────────────────────────────────────────────┐
   │ 9. git worktree remove (cleanup temp directory)     │
   └──────────────────────┬──────────────────────────────┘

                          ▼
                  ✅ Patterns on MR branch
                  Ready to merge with dev

=========================================

   outage-2312 (MR source branch):

   ──A──B──C──D──[pattern commit]──
                       │
                       │  (this is just another commit on the branch)
                       │
                       ▼
   MR: outage-2312 → dev
                       │
                       │  (when MR merges, ALL commits merge)
                       │
                       ▼
   dev:
   ──X──Y──Z──[merge commit]──
                  │
                  └── includes pattern commit ✅

7. ERROR RECOVERY
==================

   Any step fails in worktree?
        │
        ▼
   ┌─────────────────────────────────┐
   │ Recovery:                       │
   │  1. cd /                        │
   │  2. git worktree remove --force │
   │  3. Continue to next step       │
   │                                 │
   │ Pattern commit = best-effort    │
   │ Review = never blocked          │
   │ Reviewer's files = never touched│
   └─────────────────────────────────┘

   ┌─────────────────────────────────────────────────┐
   │ Error                    │ Response              │
   ├─────────────────────────-┼───────────────────────│
   │ git fetch fails          │ HARD GATE → stop      │
   │ MR not found (404)       │ Error → stop          │
   │ Review toolkit fails     │ Fallback to manual    │
   │ MR already merged        │ Skip worktree entirely│
   │ Worktree creation fails  │ Skip patterns         │
   │ Unexpected files changed │ Abort commit, cleanup  │
   │ Push fails               │ Cleanup worktree      │
   │ GitLab issue fails       │ Log warning, continue │
   └─────────────────────────-┴───────────────────────┘
